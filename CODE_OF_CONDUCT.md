# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In Short

- Be respectful and welcoming, whatever someone's background or experience.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the project and its community.
- Harassment, insults, personal attacks and publishing others' private
  information are not acceptable.

## Enforcement

Report unacceptable behavior to the maintainer at cikefallinos@gmail.com. All
reports will be reviewed promptly and handled confidentially. The maintainer may
remove, edit or reject comments, commits, issues and other contributions that
do not follow this Code of Conduct.
