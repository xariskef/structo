# Administration Application

Next.js App Router administration scaffold.

Initial administration areas:

```text
Platform dashboard
Organization dashboard
Site dashboard
```

Current administration flows include:

- Owner registration and login pages
- Session logout
- API-backed organization and site switchers
- Organization site listing and creation
- Organization and site dashboard shells
- Site settings editing
- Site-scoped custom post-type creation and activation
- Dynamic field schema editing with nested groups and repeaters
- Draft content entry editing, publishing, archival and revision history

Set `NEXT_PUBLIC_API_BASE_URL` when the API is not served from the local
`http://localhost:3001/api/v1` default.
